# PreOne — Domain Integration Matrix (M01)

**References:** PreOne DDD (bounded contexts) · PRD (module map) · BRC (business rules) · ADRs (tenancy/RBAC/audit/API) · ERD/Prisma Schema v3.0 · API Contract Catalog
**Reads the matrix as:** each row = a bounded context; what it reads/writes, the events it produces/consumes, and the scope invariants it preserves. "Read" = published API/domain-service access; private table coupling is forbidden (Spec §47).
